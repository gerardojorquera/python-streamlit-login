# Interfaz de Inicio de Sesión Rápida con Streamlit

## 📝 Descripción
Este proyecto es una aplicación web interactiva que implementa un sistema de autenticación de usuarios (Login) centralizado en una sola página. Utiliza un framework de desarrollo rápido para construir interfaces gráficas profesionales en cuestión de minutos, eliminando la necesidad de escribir código HTML, CSS o JavaScript.

## 🎯 Objetivo
El objetivo principal es validar flujos de acceso de manera local mediante el uso de estructuras de datos internas. El sistema opera bajo los siguientes criterios técnicos:
* **Formulario reactivo:** Despliega campos de captura de datos seguros (con máscaras de privacidad para la contraseña) que se actualizan de forma inmediata ante las acciones del usuario.
* **Validación interna:** Contiene un diccionario de datos seguro (`USER_CREDENTIALS`) que almacena los usuarios autorizados. Puedes realizar pruebas de acceso exitosas ingresando las siguientes credenciales de demostración:
  * **Usuario:** `gerardo`
  * **Contraseña:** `python123`

## 🚀 Aplicación y Casos de Uso
Esta arquitectura es perfecta para científicos de datos, ingenieros de software o desarrolladores que necesitan proteger sus herramientas internas o paneles de visualización sin montar servidores web complejos.

**Casos de uso principales:**
* **Protección de Dashboards:** Restringir el acceso a paneles de analítica de datos o reportes empresariales confidenciales.
* **Interfaces para Modelos de IA:** Crear una capa de seguridad antes de permitir que un usuario interactúe con un modelo de Machine Learning o un bot local.
* **Prototipado veloz:** Diseñar y probar flujos de experiencia de usuario (UX) en aplicaciones internas de la empresa antes de pasar a producción.

**Impacto:** Permite desplegar aplicaciones web funcionales y estéticas a una velocidad increíble utilizando únicamente código Python puro, optimizando los tiempos de entrega de herramientas internas para los equipos de trabajo.
